# Bloom App - Project Instructions

## Overview
Women's health & life assistant mobile app. All user-facing text in Turkish.

## Tech Stack
- Backend: NestJS + Prisma + PostgreSQL at `nodejs_space/`
- Frontend: React Native (Expo, expo-router) at `react_native_space/`
- No NativeBase or react-native-paper - custom UI components only

## Design System
- Primary: #8B5CF6, Pregnancy: #F59E0B, Period: #F43F5E, Relationship: #EF4444, Community: #10B981
- Theme: `src/theme/colors.ts` + `src/theme/useTheme.ts` (dark mode support)
- 8pt grid spacing, 12-16px border radius

## Auth
- Email/password + Google SSO
- AuthContext at `src/contexts/AuthContext.tsx`
- Layout guards in `_layout.tsx` files with `<Redirect>`
- Token stored in AsyncStorage key `auth_token`

## Navigation (expo-router)
- `/auth/` - login, register, forgot-password, callback
- `/setup/` - module selection, pregnancy, period, relationship setup
- `/tabs/` - 5 tabs: home, tracking, community, story, profile
- `/pregnancy/` - index, weeks, [weekNumber]
- `/period/` - index, symptoms, history
- `/story/` - couple-profile, create-date, dates
- `/community/` - create, [postId], user/[userId]
- `/profile/` - edit, notification-settings, privacy-settings, account-settings
- `/notifications` - notification list

## API Integration
- Generated hooks from `@/src/api/generated/api`
- Types from `@/src/api/generated/schemas`
- Never edit generated files
- customFetch handles auth token + BASE_URL automatically

## Key Features
- Dashboard with pregnancy/period/relationship cards + daily tips + recent posts
- 40-week Turkish pregnancy content
- Period calendar with fertile window + ovulation tracking
- Symptom tracking with severity levels
- Relationship tracking with special dates
- Community posts with comments, likes, saves, reports
- Notification system
- Settings: modules, notifications, privacy, account management

## Health Disclaimers
- Pregnancy: "Bu genel bilgilendirme amaçlıdır, doktor tavsiyesi değildir."
- Period/Fertility: "Bu bir tahmindir, kesin doğum kontrol yöntemi değildir."
